## 🧩 项目概览

四个入口，分工如下。前两者需先按[快速开始](#-快速开始)备好运行时与素材。

| 入口 | 作用 | 需要运行时 |
|---|---|---|
| `index.html` | 角色档案页（世界观 + Labmem 名鉴），纯静态 | 否 |

> 💡 首页顶部有「作品 / 角色 / 技术」三个锚点，以及剧情、LAB 两个入口。从剧情页右上角「编辑 ↗」进入工作台；编辑页与播放页各用一个 wasm 实例，互不干扰。

## 🚀 快速开始

> 🎯 目标：从一条空白命令到浏览器看到角色，全程约 5 分钟（不含下载 SDK 与素材的时间）。

### 1. 装 Node.js

```bash
node -v        # 应输出 v18.x 或更高
```

没有输出或版本低于 18：去 [nodejs.org/zh-cn/download](https://nodejs.org/zh-cn/download) 下 **LTS 版**，一路默认安装，**重开终端**后再执行上面的命令。

> 💡 项目零依赖，**不需要** `npm install`，也没有 `package.json`。

### 2. 拿代码

```bash
git clone <你的仓库地址>
cd steins-gate-lab-stage
```

### 3. 准备运行时（必需）

把申请到的 E-mote SDK 文件按下面放好：

```
driver/
  emotedriver.js
  emotedriver.wasm      # 本项目验证于 driver_wasm_modularize 构建
  emoteplayer.js
```

- 申请地址：[M2 Co., Ltd. E-mote SDK](https://emote.mtwo.co.jp/)。
- 验证：`driver/` 下能同时看到这三个文件即可。

> ⚠️ SDK 为专有软件，条款禁止再分发。**不要把 `driver/` 提交到任何公开仓库**，本项目也不会提供。

### 4. 准备素材（按需）

在仓库根目录建好下列目录，把文件直接丢进去（文件名随意，页面自动扫描）。这些同样被 `.gitignore` 排除，需自备。

| 目录 | 放什么 | 必需 | 缺失表现 |
|---|---|---|---|
| `character/data/<角色>/<名称>.pure.psb.zip` | 角色模型，每个 zip 内含一个 `pure.psb` | 播放必需 | 角色 tab 为空 |
| `static/background/` | 背景图 | 建议 | 背景为空 |
| `static/bgm/` | 背景音乐 | 可选 | 音乐列表为空 |
| `static/sfx/` | 声效 | 可选 | 声效列表为空（**不会**退回 BGM） |
| `character/sounds/` | 语音音频 | 可选 | 静音跳过，不影响演出 |

> 💡 素材须从你合法持有的副本中提取。模型放入后刷新页面即自动出现，无需构建步骤。缩略图 `.thumbs/` 由页面自动生成。

### 5. 启动

| 系统 | 操作 | 说明 |
|---|---|---|
| Windows | 双击 `run.bat` | 自动开浏览器；换端口：`run.bat 8901` |
| macOS / Linux / Git Bash | `./run.sh` | 自动开浏览器；换端口：`./run.sh 8901` |
| 任意（手动） | `node main.mjs --port 8000` | 默认 `127.0.0.1:8899`，不自动开浏览器 |

脚本默认端口 **8000**，直接 `node main.mjs` 默认 **8899**，别记混。

### 6. 验证成功

浏览器打开 <http://127.0.0.1:8000/>，能看到角色档案首页即启动成功。点「LAB」看立绘，点「剧情」看剧本播放。

> ⚠️ 必须通过 HTTP 访问。**直接双击 `index.html`（`file://`）会失败**：`fetch` 在 `file://` 下被浏览器禁止。

### 7. 排错

| 症状 | 原因 | 解决 |
|---|---|---|
| `run.bat` 闪退并提示 Node 未找到 | Node 没装或没进 PATH | 装 LTS 版，重开终端，`node -v` 验证 |
| 提示「端口被占用」 | 8000 已被别的程序占用 | 换端口：`run.bat 8901` / `./run.sh 8901` |
| 页面空白、控制台报 `fetch` 失败 | 用 `file://` 打开 | 改用 `http://127.0.0.1:<端口>/` |
| 角色列表为空 | 模型没放对位置 | 核对 `character/data/<角色>/` 下是否有 zip |
| 立绘起不来、报 wasm 错 | `driver/` 文件缺失 | 补齐第 3 步的三个文件 |
| 保存剧本失败 | 静态服务器只读 | 用本项目 `main.mjs`，它提供写盘接口 |

## 🖥️ 本地服务与语音

`main.mjs` 是零依赖静态服务（Node 18+，默认 `8899`，仅监听 `127.0.0.1`）。相比 `python -m http.server`，它多出写盘接口：

| 接口 | 作用 |
|---|---|
| `GET/PUT /api/order` | 读写角色顺序 `character/actions_config/order.json` |
| `GET /api/thumbs`、`PUT /api/thumb` | 背景缩略图落到 `static/background/.thumbs/` |
| `GET/PUT /api/story` | 读写 `steins_gate/edit/cast.json` 与 `steins_gate/edit/scenes/*.json` |
| `GET /api/voice` | 列出即时台词音频（`steins_gate/story/voices/`） |
| `GET /api/voice?name=…` | 流式播放音频，支持 Range（可拖进度） |
| `POST /api/voice`（octet-stream） | 外部导入音频，上限 12MB |
| `POST /api/voice`（json） | 文字 → 语音合成（TTS 预留） |

> 💡 页面里的「选择音频」「音频列表」**都不走**写盘接口，只在浏览器内播放。

**语音三来源**

| 来源 | 行为 | 是否写盘 |
|---|---|---|
| 选择音频 | 选本地文件，blob URL 播放 | 否 |
| 音频列表 | 从 `character/sounds/` 静态播放 | 否 |
| 文字合成 | 需配 `EMOTE_TTS_BIN`（如 `edge-tts`）、可选 `EMOTE_TTS_VOICE`（默认 `zh-CN-XiaoxiaoNeural`）；未配置返回 501 | **是**，落到 `steins_gate/story/voices/` |

外部命令需支持 `--voice <名> --text <文字> --write-media <文件>`。

> 📌 换用其他静态服务器也能播放，但写盘能力退化为只读：剧本无法保存、排序只在本次会话有效、缩略图只用已有文件、TTS 不可用；音频两种来源照常。

## ✨ 功能特性

| 特性 | 说明 |
|---|---|
| **模型直读** | 直接解析 `.pure.psb`（PSB v4），无需反编译、预生成配置或构建；模型丢进 `character/data/` 即自动出现 |
| **手臂姿势切换** | 在 GPU 纹理上传阶段擦除未选中的 PSB 4.0 互斥手臂，兼容 3.9.8 运行时 |
| **触摸反应** | 按 `charaProfile` 部位命中，随机抽动作，可带语音与变量插值 |
| **口型同步** | WebAudio 离线分析包络 + rAF 查表驱动 `face_talk`；音频失败明确告警并跳过 |
| **场景 UI** | 角色 tab、造型面板、背景预览、tab 排序写回 `order.json` |
| **剧情播放** | 打字机、点击 / AUTO 推进、语音、动作宏；多角色同台、行内上下场与走位 |
| **编辑工作台** | 独立页面写剧本、排多轨时间轴（台词 / BGM / 声效 / 语音 / 背景），编辑↔播放无缝续播 |
| **开发者面板** | LAB 页内置选择器 / 姿势 / 变量调试入口 |

**剧情演出的几个细节**

- **等待齿轮**：打字结束后句末出现旋转齿轮（原作 37 帧烘焙图），前 17 帧展开、后 20 帧循环；AUTO 开启时隐藏。
- **对话框开场**：照 `MSGWIN.show` 复现，白线两侧擦入 / 擦出、窗底擦入，末态回到干净常态。
- **名牌动画**：`show → deco_show → name` 三段串行；装饰线由中间向两边亮起，名牌做 mesh 形变出场，名字末段浮现。
- **角色卡**：每个登场角色一张卡；换角色时继承旧角色本场全部行为（说话者、上下场、走位、cues）。

## 📖 场景数据格式

> 📌 本节是剧情字段的**唯一权威出处**。可运行示例：`steins_gate/edit/scenes/demo.json`。

一个场景可让多名角色同台。`cast.json` 先绑定角色 → 模型，场景用 `stage` 声明谁上场、站哪。

```json
{
  "title": "二人对话",
  "background": "background.jpg",
  "bgm": [
    { "file": "theme.mp3", "range": [1, 4] },
    { "file": "climax.mp3", "range": [5, 12] }
  ],
  "sfx": [
    { "file": "door.wav", "at": 2 }
  ],
  "stage": [
    { "role": "红莉栖", "x": -0.35, "scale": 1, "z": 0 },
    { "role": "铃羽",   "x":  0.38, "scale": 1, "z": 1 }
  ],
  "lines": [
    { "role": "红莉栖", "text": "你来了。", "action": "平常", "exit": ["铃羽"] },
    { "role": "铃羽",   "text": "抱歉，我来晚了！", "enter": ["铃羽"] },
    { "role": "铃羽",   "text": "别站在门口，进来。", "action": "微笑",
      "cues": { "红莉栖": { "action": "惊讶" } } },
    { "role": "铃羽",   "text": "……我站这边就好。", "move": { "铃羽": -0.1 } },
    { "role": "铃羽",   "text": "先走了。", "exit": ["铃羽"] }
  ]
}
```

**字段速查**

| 字段 | 位置 | 含义 |
|---|---|---|
| `title` / `background` | 场景 | 标题 / 背景图 |
| `bgm` | 场景 | 背景音乐段列表，见[背景音乐](#背景音乐-bgm) |
| `sfx` | 场景 | 声效段列表，见[声效](#声效-sfx) |
| `fadeMs` | 场景 | 上下场与换背景的淡化时长（毫秒，默认 300） |
| `stage` | 场景 | 本场默认登场角色与站位，可省略，见[登场阵容](#登场阵容-stage) |
| `role` | 行 | 说话者；留空 `""` = 旁白（不显示名牌，装饰线照常） |
| `text` / `name` | 行 | 台词 / 对话框显示名 |
| `action` / `voice` | 行 | 说话者动作宏 / 语音文件 |
| `enter` / `exit` | 行 | 本行中途上 / 下场的角色 |
| `move` | 行 | 本行站位调整 |
| `cues` | 行 | 同台其他角色本行的演出 |
| `wait` | 行 | AUTO 时在本句语音外额外停顿 |

### 背景音乐 bgm

`bgm` 可选、可多段，每段：

- `file`：`static/bgm/` 下的文件名。
- `range: [起, 止]`：1-based 闭区间句号，`[1,3]` = 第 1~3 句。区间内循环，跨行不打断、不重播。
- `fadeIn` / `fadeOut`（布尔，默认 `false`）：渐入约 1 秒；渐出在停止或切段时生效。试听与播放都有效。

> 🎛️ 编辑器：属性面板列出 `static/bgm/` 音频，拖到行右侧 BGM 竖轨落段；拖整段平移、拖上下边缘改长度，按句号吸附。点段可改起止、试听、切淡入淡出、删除。

### 声效 sfx

`sfx` 可选、可多段，写法与 `bgm` 类似：

- `file`：`static/sfx/` 下的文件名。
- `at`（必填）、`to`（可选）：1-based 闭区间句号，`to` 省略即只触发一句。

```json
"sfx": [
  { "file": "door.wav", "at": 2 },
  { "file": "alarm.wav", "at": 5, "to": 8 }
]
```

> ⚠️ `static/sfx/` 为空时声效列表就是空，不会拿 BGM 顶替——两者不是一回事。

### 登场阵容 stage

`x` 为画布宽度比例（-1 左 / +1 右），`y` 为高度比例（-1 下 / +1 上，默认 0），`scale` 相对缩放，`z` 叠放次序——这是**本场默认站位**。

- 台词里写过 `enter` 的角色开场隐藏，其余开场在台；之后的上/下场由 `enter` / `exit` 决定。
- `stage` 可省略：按台词里出现的角色自动均分站位。

> 🎛️ 编辑器「登台角色」一张卡就是一个角色。卡顶换角色时，新角色**继承旧角色本场全部行为**，旧引用一并清掉；第二排 X / Y 分别调横向与纵向位置。

### 上下场淡入淡出

场景顶层 `fadeMs`（数字，毫秒，**默认 300**）同时控制角色上下场与背景切换；单行可写 `fadeMs` 覆盖：

```json
{ "title": "夜", "fadeMs": 600, "lines": [
  { "role": "铃羽", "text": "我来了。", "enter": ["铃羽"] },
  { "role": "红莉栖", "text": "等等。", "fadeMs": 1200, "exit": ["铃羽"] }
] }
```

角色透明度走 SDK 内部 `_globalA`，不额外占帧；背景先预载再交叉淡入，不闪黑。编辑态选行、重放历史行只落终态；首句随对话框开场就位，不单独淡入。

### 站位与显示名

- `move`：本行站位调整。值可为 `x` 数字（只改横向）或 `{ x, y, scale, z }`（只写要改的字段）。写一次一直生效到下次调整，不必每句重复。
- `name`：这一句起对话框显示的名字。同样写一次沿用，直到同角色下次改写。省略沿用上一句。

```json
{ "role": "红莉栖", "text": "你是谁？", "name": "？？？" },
{ "role": "红莉栖", "text": "别用那种眼神看着我。" },
{ "role": "红莉栖", "text": "……算了，我是牧濑红莉栖。", "name": "红莉栖" }
```

`cast.json` 里的 `name` 是全局默认，不写用键名。键名是内部 id（剧本、语音目录、模型绑定都挂它上面），改显示名不断引用。

**旁白**：`role` 留空即旁白——不显示名牌，装饰线照常；打字机与 AUTO 正常。编辑器下拉选「旁白」后，该行显示名输入框禁用。

### 同台演出 cues

`cues` 是同台其他角色本行的演出，写法与行级相同（`action` / `voice` 都可省略）：

```json
"cues": {
  "红莉栖": { "action": "惊讶", "voice": "resg00_01_krs0005.xwma.opus" },
  "铃羽":   { "action": { "timeline": "表情_笑う", "diffSlot1": "ひく", "diffSlot2": "" } }
}
```

动作对象只有三个字段：`timeline`（主时间线）、`diffSlot1` / `diffSlot2`（两条独立差分槽）。省略＝不动，写空串＝显式清空。

> 🔊 每个角色一台音频播放器，语音与口型只落在自己身上，两人同时开口不互相打断。

### 自动推进 AUTO

不是行字段，是对话框左下角 `AUTO` 全局开关（原生 `main.psb.m` 切片，`left:26 / top:1022`）。亮起后每句等说话者语音播完（加本行 `wait`）自动翻页；点击画面可立即继续。状态记在 localStorage，刷新后保持。

### 眨眼 blink

节奏跟 wasm 自带自动眨眼走，每 1.3–3s 沿 10 帧曲线把 `face_eye_open` 抬到 `10`（闭）再回落。

- 配置在**角色级**：`cast.json` 的 `blink`（`on` 默认 `true`，`closeValue` 默认 `10`；`vars` / `track` 可换名）。
- **动作不再单独覆盖**，所有动作跟随角色这一套。
- 站位落定后给全员起表；翻页 / 换场 / 结局 / 进编辑模式停表并归零。

<details>
<summary>🔍 展开：眨眼的内部机制</summary>

**变量自适应**：`face_eye_open_l` / `_r` 才是眼皮线（0 睁 / 5 半 / 10 闭 / 55 特殊），SDK 只驱动单数 `face_eye_open`，所以 L/R 要我们补；模型没声明这两个变量的就不写，避免双倍闭合。

**驱动**：`setVariableDiff`（模块 `blink`），叠加在基准上，停手写回 0。每帧一次线性跟随：

```
k    = (track - trBase) / (10 - trBase)
diff = (closeValue - 眼皮实时值) * k
```

两个关键点：

1. **相对基线**：静止值会被表情抬高（铃羽生气 = 2、红莉栖吃惊 = 8）。基线按变化速率认：慢于 `0.015` 单位/ms 算表情渐变，直接跟随；快变（眨眼 0.02~0.12）后 250ms 内不认漂移，免得把峰值误当基线。
2. **补差量而非加常量**：眼皮基准不是 0（吃惊 -5、生气 4），直接 `+closeValue` 会闭不满或越界。

**兜底**：`track` 顶在满闭超过 250ms 不落，判为动作压眼（如铃羽摇头），改认基线、diff 归零。diff 无 remove 接口，停表 / 换变量 / 关眨眼 / 换动作都必须显式写 0。

</details>

## 🎛️ 编辑工作台

入口：`steins_gate/edit/index.html`（从剧情页「编辑 ↗」进入）。独立 wasm 实例，编辑与播放来回切换不断内存。

**顶栏三视图**

| 视图 | 内容 |
|---|---|
| 剧本 | 台词编辑 + 多轨时间轴（台词 / BGM / 声效 / 语音 / 背景） |
| 时间轴 | 全轨概览、拖动滑块、框选删除 |
| 角色表 | 角色 / 动作宏 / 属性 三栏，全景核对、重命名、删除（`Esc` 退回） |

**布局**：左栏「项目抽屉」（剧本 / 标题两行）+「资源抽屉」（背景 / 背景音乐 / 声效 / 改动历史，可拖拽排序、折叠记忆）；右栏「台词 / 语音库 / 登台角色」三张卡。抽屉宽度与排序记在 localStorage。

**要点**

- **登台角色**一张卡四排：角色下拉 + 上/下场 + 移除；位置与缩放（第 1 行写入 `stage`，之后写 `move`，灰色沿用 / 橙色覆盖）；本行动作与语音（说话者写行级，其他写 `cues`）；绑定（模型下拉 + 语音目录）。
- **动作宏**：选「自定义…」展开主时间线 / 差分槽 1 / 差分槽 2 三个下拉，填名字点「存为宏」写入 `cast[role].actions`。
- **显示名随处可见**：行列表、说话者下拉、角色卡下拉都显示 `cast` 显示名（有自定义名带内部 id）。
- **只有一个「保存」**：场景与 `cast.json` 一次写完；角色表无独立保存。
- **变量导入**：LAB 页「变量微调」→「复制参数」，到角色表动作宏 →「粘贴导入」批量追加变量行；变量名下拉来自当前模型 `variableList`，可选「自定义…」输入新名；`Ctrl+Enter` 快速导入。
- **主题切换**：顶栏调色板按钮切换「青绿 / 石墨橙」两套配色，记在 localStorage。

> 💡 切换场景需要新模型会整页重载一次；角色卡换模型会提示「保存后刷新页面生效」。

## 🔧 技术要点

**为何自己解析 PSB**：wasm 导出 84 个接口，模型元数据却只给 `charaProfile` / `charaBounds`，不暴露图集矩形、`source` 表、`customSelectorList`。互斥手臂在 SDK 层无法枚举，只能读字节——这是 `PsbReader` 存在的唯一理由。解析器只读结构区（约 1MB），跳过约 200MB 贴图，浏览器内约 10ms。

**为何在纹理层打补丁**：运行时是 3.9.8，不懂 PSB 4.0 的 `insert` / `delete`，会把两套手臂全画出来。改为在 `texImage2D` 上传图集时把未选中的手臂矩形擦透明，SDK 无需改动。

## ⚠️ 已知限制

- 仅支持未加密、未压缩的 PSB v4 `pure.psb`；MDF / PSZ 壳、PSB v3、其他平台导出需扩展。
- 依赖 3.9.8 运行时；SDK 版本变化可能影响纹理补丁假设。
- 触摸命中区依赖模型 `charaProfile`，缺失则降级为无反应。
- 缩略图按原图文件名存放；同名新图替换后旧缩略图不会失效，删掉 `.thumbs/<原名>.jpg` 重新生成。
