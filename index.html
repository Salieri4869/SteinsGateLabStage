研究所页面怎么玩

显示／隐藏控制条：控制条默认固定展开，从左到右是「← 主页」→ 一排角色 tab → 「⇅ 排序」「切换背景」「▲ 隐藏」。点「▲ 隐藏」收起后，鼠标移到页面顶端即在右上角滑出 「← 主页 ／ ▼ 显示控制条」，点提示条任意处或按 ESC 都能立刻展开。

返回主页：控制条最左侧的「← 主页」可一键回到作品介绍页；控制条收起时， 顶部滑出的提示条里也保留同一个主页入口。

切换角色／造型：在 data/ 下建角色文件夹，把 *.psb 或 *.zip 丢进去，刷新后自动出现在 tab 上；点角色 tab 展开造型面板，点造型才切换。

调整顺序：控制条「⇅ 排序」里拖动 ⠿ 或点 ▲▼，松手即写回 actions-config/order.json。用 run.bat 启动才能写盘， 普通静态服务下顺序只在本次浏览有效。

切换背景：「切换背景」打开预览面板，悬停看大图、点击即应用并记住选择。 背景由浏览器运行时发现：直接把图片丢进 background/，面板点「↻ 重新扫描」就会读到； 缩略图由页面生成一次、写进 background/.thumbs/，之后卡片与预览都读这张 720p 小图。 分组与标签按文件名推断。若服务器不返回目录索引，面板会出现「导入文件夹」，手动选一次即可。

控制台：页面右侧竖条，展开后可调整差分、变量、部件与时间线。面板从顶部控制条下方开始， 与造型／排序／背景面板互斥；按 ESC 会按 「排序 → 造型 → 背景 → 控制台 → 顶部控制条」的顺序逐层收起。

扩充名鉴／角色：名鉴由本页底部的 LABMEM 与 OTHERS 两份名簿驱动， 追加角色只需在对应数组加一行（有编号 / 无编号）。研究所页面里的造型不用登记， 放进 data/ 就会被扫描到。

由于 wasm 与 zip 通过 fetch 加载，直接以 file:// 打开会被浏览器拦截， 请双击 run.bat（或执行 node main.mjs --port 8000）启动本地服务后访问本页。
